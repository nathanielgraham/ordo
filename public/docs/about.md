# Ordo: Giving AI Real Hands

**The execution layer that turns AI reasoning into real-world action.**

While AI has become extraordinarily good at thinking and planning, it has historically been powerless to *do* anything on its own. Ordo changes that.

We built Ordo as the missing bridge — a modern, self-hosted job scheduler with native MCP (Model Context Protocol) support. This allows Grok (and other AI agents) to directly explore, create, monitor, and execute real work on your infrastructure.

### The Problem

Today's best AI systems are trapped behind chat interfaces.

They can design sophisticated workflows, but can't run them.  
They can analyze your systems, but can't touch them.  
They can reason brilliantly, but still need humans to act as their hands.

Legacy tools (cron, AutoSys, Control-M, cloud schedulers) are rigid, expensive, and completely disconnected from AI.

### The Solution

**Ordo** is a hierarchical job scheduler built for the AI era.

Through its native **MCP connector**, Grok can:
- Browse your entire job hierarchy in real time
- Create complex jobs in Shell, Python, Perl, and more
- Build powerful recurring schedules using Quartz calendars
- Debug failures, read logs, and manage dependencies
- Act as a true autonomous agent on your own servers

You stay in full control. Everything runs on **your** infrastructure. Nothing is sent to third-party clouds.

### What You Can Do With Ordo + Grok

Here are just a few real things users are already doing:

- **Infrastructure Monitoring** — Ask Grok to create jobs that alert you when disk space, memory, or services cross thresholds.
- **Automated Backups** — Have Grok build and schedule sophisticated backup workflows with proper logging and error handling.
- **Daily Reports** — Let Grok create Python or Perl jobs that generate and email reports on system health or business metrics.
- **Self-Healing Systems** — Build jobs that automatically restart failed services or clean up temporary files.
- **Complex ETL Pipelines** — Create dependency chains that pull data, process it, and load it on precise schedules (including business-day logic).
- **One-off Maintenance** — Ask Grok to run ad-hoc cleanup or migration tasks safely.

### Key Advantages

- **Native Grok Integration** via MCP — Grok can reason *and* act
- **Powerful Quartz Scheduling** — Supports seconds, years, and advanced tokens (e.g., "third Monday in January")
- **Hierarchical Design** — Jobs organized in logical clusters with dependency graphs
- **Self-Hosted & Private** — Full control and data ownership
- **Beautiful Real-Time UI** — Designed for both humans and AI agents
